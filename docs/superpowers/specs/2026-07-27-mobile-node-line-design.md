# 移动端 Node Line 设计

## 目标

用左侧固定节点线取代移动端顶部导航。用户点击任一节点后立即获得视觉反馈并滚动到对应区块；手动滚动时，高亮稳定跟随最接近内容顶部的区块。

## 交互

- 仅在小于 `sm` 的宽度显示左侧节点线；桌面端保留全部文字导航。
- 节点线包含全部七个页面区块。当前节点显示实心圆点和名称标签，其余节点显示空心圆点。
- 每个节点是可聚焦的原生按钮，最小触控区域为 44×44 px，并带有清晰的无障碍名称。
- 点击节点时先更新激活状态，再复用现有平滑滚动逻辑。
- 滚动时，以滚动容器当前顶部经过的最后一个区块为激活区块。该策略不依赖区块高度与可见比例。

## 非目标

- 不在移动端保留“更多”下拉菜单或原生 select。
- 不改变桌面导航、内容顺序和滚动动画偏好设置。

## 验证

- 单元测试覆盖点击节点、立即高亮和滚动后的高亮同步。
- 移动尺寸的浏览器检查确认七个节点可见、选择后无菜单残留。

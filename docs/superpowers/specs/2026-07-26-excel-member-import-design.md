# LEC 近三年人员 Excel 导入设计

## 目标

使用用户提供的 `LEC近三年人员信息 (1).xlsx` 替换官网中的成员与优秀成员 Mock 数据，并保留现有技术方向、版式和交互。

## 数据映射

- 工作表：`Sheet1`；字段：年级、方向、专业、姓名、毕业去向。
- 由于 Excel 使用合并单元格，导入时对年级与方向采用向下填充。
- 19–23 级记录导入为优秀成员；24、25 级记录导入为在读成员。
- “方向”字段按实际语义映射为去向：保研 → `recommendation`，考研/深造 → `graduate-exam`，就业/考公 → `employment`。
- 优秀成员卡片展示姓名、去向标签、毕业去向，并将专业作为补充信息。
- 在读成员展示姓名与专业；不将 Excel 的去向类型显示为在读成员身份。

## 异常行与内容规范

- 单独标记为“在读”的行按所在年级上下文归并，但不进入优秀成员数据。
- 空白姓名、占位姓名和不完整记录不渲染；导入测试会明确记录过滤数量。
- 24、25 年级中的去向信息不作为正式毕业结果展示。
- 现有 `membersContent`、`alumniContent` 等展示文案与七个技术方向不由 Excel 覆盖。

## 架构

Excel 只作为一次性来源文件；官网运行时继续读取版本控制中的 TypeScript 数据模块。新增一个可重复执行的导入脚本：读取工作簿、规范化字段、输出 `src/data/members.ts` 与 `src/data/alumni.ts` 的数据数组。脚本不上传、保存或修改原始 Excel。

## 验收标准

1. 官网不再显示成员与优秀成员的 Mock 姓名。
2. 19–23 级显示在优秀成员区；24、25 级显示在读成员区。
3. 去向标签、专业和毕业去向字段按以上规则显示，且无空白卡片。
4. 现有成员筛选、优秀成员分届、移动端布局、测试与 production build 保持可用。

# LecOrg 官网内容扩展设计

## 目标

参考已上线的乐程软件工作室网站，向当前官网补充可用于招生与团队介绍的真实内容，同时保留已完成的手绘视觉、优秀成员展示、顶部导航与分段浏览体验。

## 范围

- 扩展“关于我们”内容，使用参考站的团队图片与更完整的团队介绍。
- 新增“团队成就”“技术方向”“招新报名”三个主区块。
- 顶部导航扩展为：首页、关于、成就、方向、成员、优秀成员、历史、招新八个入口。
- 招新信息使用可长期复用的“每年 8–10 月”表述，不写固定年份。
- 招新对象为全体大一新生；地点为明理楼 C 栋 10 楼 C1010；官方群号为 674764635。
- 将从参考站迁移的图片保存为本地静态资源，不依赖线上图片地址。

## 不在范围内

- 在线报名表单、群聊跳转、二维码生成或外部服务接入。
- 修改当前在读成员、优秀成员或历史的正式数据来源。
- 复刻参考站的完整交互或重写当前手绘设计语言。

## 页面结构

### 关于我们

现有宗旨区调整为“关于我们”。团队简介包含成立时间、约 30 人规模、每周 28 小时考勤、例会与学习交流、项目与竞赛实践，以及“学以致用，服务学校，走向社会”的宗旨。下方使用由本地图片组成的可访问图片墙；桌面端呈现轻量错位拼贴，移动端回退为可顺序阅读的网格。

### 团队成就

新增独立区块，用易扫描的数据卡展示：省级奖项 100+、国家级奖项 50+、团队项目多次获学院立项、毕业生去向（大厂/名校深造）。赛事名称以参考站已有的全国大学生软件大赛、挑战杯、天梯赛、CCF CAT、ACM-ICPC 为示例标签，不将未核实获奖结果写成具体事实。所有数字与文案集中在数据模块，标注为待正式资料确认。

### 技术方向

新增独立区块，展示算法、前端开发、后端开发、游戏开发、机器学习、图形学、人工智能七个方向。每个方向使用简短说明、图标和手绘卡片表达；不增加详情页或外部链接。

### 招新报名

新增独立区块，使用“每年 8–10 月”招新周期、全体大一新生、明理楼 C 栋 10 楼 C1010 与官方招新群 674764635。二维码从参考站迁移并作为本地图片展示；信息文字始终与二维码并列，以保障二维码无法识别时仍可联系。

## 架构与数据

- 团队介绍、成就、技术方向与招新信息均由 `src/data` 模块提供，以便后续与 Excel 或确认资料同步。
- 新建三个展示组件：`Achievements`、`Directions`、`Recruitment`；关于图片墙作为 `Mission` 内的独立小组件或单独组件。
- 新增 section id 进入 `src/config/sections.ts`，沿用现有 `Layout` 的可访问导航、滚动与减少动态效果支持。
- 图片存入 `public/about/` 与 `public/recruitment/`，使用稳定的本地路径和描述性替代文本。

## 可访问性与响应式

- 每个图片区块提供准确的替代文本；纯装饰图片不重复播报。
- 新增八个导航入口都可由键盘访问并正确反映当前区块。
- 桌面保持相邻 section 的受控分段切换；移动端和减少动态效果用户保持自然滚动。
- 图片墙、成就卡、方向卡和招新信息在窄屏单列或双列显示，不产生横向裁切。

## 验收标准

1. 当前站点新增关于图片墙、团队成就、技术方向与招新报名四项内容。
2. 招新时间显示为“每年 8–10 月”，并展示地点、对象、官方群号和本地二维码。
3. 八个导航入口均可到达相应区块；桌面、移动和减少动态效果行为保持当前约束。
4. 所有新增事实、数字与标签集中在数据模块；图片不依赖参考站 URL。
5. 新增内容在窄屏可完整阅读，页面 lint、测试与 production build 通过。
